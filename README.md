**House Price Prediction using Linear Regression**

**Overview**
This project aims to predict house prices based on various features such as area, number of bedrooms, bathrooms, furnishing status, and other property details using a Linear Regression model.
The dataset contains both numerical and categorical features that describe the characteristics of each property.

The goal is to build a regression model that can accurately estimate property prices and provide insights into which features influence house prices the most.

**Objectives**
Load and explore the House Price dataset

Handle missing values and perform data preprocessing

Encode categorical variables using Label Encoding

Apply Feature Scaling to numerical features

Train a Linear Regression model

Evaluate the model using R² Score and Mean Absolute Error (MAE)

Visualize the results using Seaborn and Matplotlib
